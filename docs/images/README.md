## Interface images

Each README uses the same home / morning check two-column layout in its corresponding language. All images are 1280 × 800 and were captured on October 29, 2026.

| File | Source and content |
| --- | --- |
| `home-landscape.png` | Chinese home screen from a YF023D, with fictional company, workplace, and device identifiers. |
| `check-landscape.png` | Chinese morning check screen from a YF023D, showing the guide while waiting for the device. |
| `home-landscape.en.png` | English home screen from an Android 35 emulator, with `Sample Workplace`, `Sample Company`, and `SN DEMO023D001`. |
| `check-landscape.en.png` | English morning check screen from an Android 35 emulator, using an isolated local SDK status fixture and waiting to identify staff. |

Identifiers are fictional. The displayed App version is edited to `2.0.0` for presentation. The Chinese images retain the existing interface; the English images were captured with the new `2.0.1` build. Editing the displayed version does not change the App version configuration. The images contain no real-person photos, actual temperature readings, or real check records. Unredacted originals are excluded from the repository and distribution package.
