# 2026-10-15 表头、选择弹窗与晨检引导修正

## 原因与修改

参考零售客户端 `common/ui/SelectOptionDialog.java`：选项在创建内容时绑定，透明背景、宽度和列表高度在 `onStart()` 中设置。晨检的 `DesignChoiceDialog` 曾把这些操作放进异步 `OnShowListener`，窗口开始显示后才移除默认背景并改变尺寸，存在白框首帧与重新布局的机会。

本轮将测量移到 `onStart()`，创建时即设置透明背景，保持零售端 40% 遮罩、可滚动选项、固定取消按钮和当前项定位。点击遮罩、取消及重选当前项均不提交。固定枚举没有 Loading 调用；通用弹窗只复制调用方提供的列表，没有内置默认选项。部门由宿主读取本地目录后传入；其“全部部门 / 未分配”是实际筛选条件。

| 内容 | 修改位置 | 设计对应 |
| --- | --- | --- |
| 员工、部门、晨检记录表头 | PenHeaderCell、view_staff_table_header、view_record_table_header、view_departments_design | ym39n / d3FlcQ、pOFpT / j4XRJS、Fz7sh / VkCYX；相关弹窗背景和列表续页也同步居中 |
| 通用选择弹窗 | DesignChoiceDialog、item_design_choice | CQeI4 交互说明；显示时序修正，外观沿用通用组件 |
| 晨检工作台 GIF | view_check_design_info、FaceAlignmentGuideView | OlRVP / f5BMbz |

表头单元格水平和垂直居中，以原高度为最小值，130% 字号允许增高。选择列表取消两行截断，长内容按实际高度测量。引导区域使用现有 dp_135 档替换 dp_90；GIF 源文字由 27 提高到 35 像素，绘制使用位图过滤，静态图同步更新。保持完整等比显示和透明背景；91 个编码帧，总长 4800ms，逐帧角落透明检查通过。

设计稿先通过 Pencil MCP 修改并保存，再修改客户端；设计预览、真机截图与测试输出在 `list-fixes-20261015/`。
